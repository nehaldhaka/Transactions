In this project, I performed exploratory data analysis on a transaction dataset to understand customer purchasing behavior, sales performance, and regional trends. The objective was to answer key business questions and derive meaningful insights from the data.

Tools & Technologies
Python
Pandas
NumPy
Matplotlib
Jupyter Notebook

Analysis :

Evaluated total and monthly sales trends
Identified top-performing services and product categories
Determined highest spending customers
Calculated repeat buyer percentage
Analyzed average spending across states and services
Examined transaction patterns across different regions


Through this project, I strengthened my understanding of:

Data cleaning and preprocessing
Grouping and aggregation techniques
Customer behavior analysis
Business-focused data interpretation

This project helped me apply data analysis techniques to a real-world transaction dataset and extract actionable business insights.
